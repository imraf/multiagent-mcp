# Agent Skills: Advanced Primitives

To successfully complete the advanced primitives tasks, you must possess the following skills:

- **MCP Resource Model:** Understanding how to expose read-only data via URI schemes (`invoice://...`).
- **MCP Prompt Model:** Understanding how to create reusable prompt templates for LLMs.
- **Templating Engines:** Using `Jinja2` to render dynamic text content.
- **URI Handling:** Parsing and routing custom URI schemes to data handlers.
- **Integration Testing:** Verifying that resources and prompts resolve correctly in the MCP context.
