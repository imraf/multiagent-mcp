# Agent Skills: Customer Module

To successfully complete the customer module tasks, you must possess the following skills:

- **Business Logic Implementation:** Writing service-layer logic for CRUD operations on Customers.
- **MCP Tool Definition:** Creating tools that adhere to the Model Context Protocol (JSON Schema generation).
- **API Design:** Designing clean internal APIs for the `CustomerService`.
- **Testing:** Writing unit tests for service logic and integration tests for tools.
