# Agent Skills: Core Domain

To successfully complete the core domain tasks, you must possess the following skills:

- **Domain Driven Design (DDD):** Ability to model complex business entities (`Customer`, `Invoice`) using Pydantic.
- **Data Validation:** Implementing strict validation rules (e.g., VAT format, email validation) within models.
- **Repository Pattern:** Designing abstract storage interfaces to decouple business logic from persistence.
- **Persistence Implementation:** Implementing file-based storage (`json`) with concurrency controls (file locking).
- **Type Safety:** Writing strictly typed Python code (`mypy` compliant).
