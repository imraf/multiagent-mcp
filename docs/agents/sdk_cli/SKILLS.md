# Agent Skills: SDK & CLI

To successfully complete the SDK and CLI tasks, you must possess the following skills:

- **API Client Design:** Building fluent, developer-friendly Python client libraries.
- **CLI Development:** Using `Typer` or `Click` to build robust command-line interfaces.
- **Terminal UI (TUI):** Using `Rich` to create beautiful, interactive terminal outputs (tables, progress bars).
- **Package Distribution:** Structuring the SDK for easy installation and usage.
- **Integration Testing:** Testing the CLI against the running server.
