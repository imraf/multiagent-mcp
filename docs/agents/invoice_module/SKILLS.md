# Agent Skills: Invoice Module

To successfully complete the invoice module tasks, you must possess the following skills:

- **Financial Logic:** Implementing precise calculations for VAT, subtotals, and totals (avoiding floating point errors).
- **State Machine Logic:** Managing the lifecycle of an invoice (Draft -> Issued -> Paid/Cancelled).
- **Sequential Numbering:** Implementing logic to ensure gapless, sequential invoice numbers.
- **MCP Tool Definition:** Creating complex tools (`create_invoice`, `finalize_invoice`) with detailed schemas.
- **Testing:** Writing property-based tests to verify financial correctness.
