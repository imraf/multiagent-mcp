# Agent Skills: Transport

To successfully complete the transport tasks, you must possess the following skills:

- **Software Architecture:** Designing Abstract Base Classes (ABCs) to decouple transport from logic.
- **Dependency Injection:** Implementing patterns to inject transport strategies at runtime.
- **AsyncIO:** Writing asynchronous Python code for non-blocking I/O.
- **JSON-RPC:** Understanding the JSON-RPC 2.0 specification for the Stdio transport.
- **Web Frameworks:** Using `FastAPI` or `Starlette` to implement Server-Sent Events (SSE).
- **Testing:** Mocking stdin/stdout and HTTP requests for testing transports.
