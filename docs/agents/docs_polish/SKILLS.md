# Agent Skills: Docs & Polish

To successfully complete the documentation and polish tasks, you must possess the following skills:

- **Technical Writing:** Writing clear, concise, and professional documentation for developers.
- **Markdown Mastery:** Creating visually appealing READMEs with badges, headers, and tables.
- **Static Site Generation:** Using `MkDocs` and `Material for MkDocs` to build documentation sites.
- **DevOps Basics:** Writing `Makefiles` and `Dockerfiles` for automation and deployment.
- **LLM Configuration:** Understanding how to configure and document local (Ollama) vs. remote (OpenAI) LLM setups.
