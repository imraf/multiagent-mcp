# Agent Skills: Infrastructure

To successfully complete the infrastructure tasks, you must possess the following skills:

- **Python Configuration Management:** Expert knowledge of `pydantic-settings` for type-safe, hierarchical configuration (Env vars, YAML, Defaults).
- **Structured Logging:** Ability to implement JSON logging (using `structlog` or standard `logging` with JSON formatters) and configure log rotation.
- **Exception Handling Patterns:** Designing custom exception hierarchies and global error handlers/decorators.
- **Project Scaffolding:** Setting up modern Python projects with `pyproject.toml`, `ruff`, and `mypy`.
- **Testing:** Writing unit and integration tests using `pytest`.
